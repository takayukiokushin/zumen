# 導入手順

このアプリは「**サーバー1台**」と「**それを見る画面**」でできている。
画面はブラウザでもデスクトップアプリでも同じものが出る。まずはブラウザで動かすのが一番早い。

---

## 1. まず自分のパソコン1台で試す

### 1-1. Node.js を入れる

<https://nodejs.org/ja> から **LTS版（22以上）** をダウンロードして、案内どおりに入れる。
入ったか確認する（macOSは「ターミナル」、Windowsは「PowerShell」を開いて）：

```sh
node -v
```

`v22.x.x` 以上と出ればよい。

### 1-2. pnpm を使えるようにする

```sh
corepack enable
```

（Windowsで「アクセスが拒否されました」と出たら、PowerShellを**管理者として実行**して同じコマンドを打つ）

### 1-3. アプリのファイルを持ってくる

```sh
git clone https://github.com/takayukiokushin/zumen.git
cd zumen
pnpm install
```

Gitを使っていなければ、GitHubのページの緑色の「Code」→「Download ZIP」で落として展開し、
そのフォルダで `pnpm install` でもよい。

### 1-4. Claude APIキーを置く

`.env.example` をコピーして `.env` という名前にし、キーを書く。

```sh
cp .env.example .env
```

`.env` をメモ帳などで開いて、`ANTHROPIC_API_KEY=sk-ant-...` の部分を実際のキーに書き換える。
**このファイルはサーバーの中だけに置き、他の人には配らない。**
キーは <https://console.anthropic.com/> で発行する。

> キーがなくても、ヒアリングから図面を作る機能は動く。
> 使えなくなるのは「手書きメモの読み取り（AI解析）」だけ。

### 1-5. 利用者を登録する

```sh
pnpm --filter @zumen/server user:add jimu 事務担当 好きなパスワード
```

`jimu` がログインID。人数分くり返す。

### 1-6. 起動する

```sh
pnpm start
```

`サーバーを起動しました: http://127.0.0.1:8787` と出たら、ブラウザでその住所を開く。
さきほどのIDとパスワードでログインすれば使える。

止めるときはターミナルで `Ctrl + C`。次からは `pnpm start` だけでよい。

## 2. 社内のみんなで使う

**1台をサーバー役にして、他のパソコンはブラウザでそこを見る**のが一番手間がかからない。
データ（案件・図面・写真）はサーバー役の1台にまとまるので、誰がどこで開いても同じものが見える。

1. いつも電源が入っているパソコンを1台決め、上の **1.** をそこで行う
2. `pnpm start` したときに表示される
   `社内の他のパソコンからは: http://192.168.x.x:8787` の住所を控える
3. 他のパソコン・iPad・スマホのブラウザでその住所を開く（同じ社内ネットワークにいること）
4. つながらない場合はサーバー役のパソコンのファイアウォールで **8787番ポート** を通す
   - macOS：システム設定 → ネットワーク → ファイアウォール → オプション で Node を許可
   - Windows：「Windows Defender ファイアウォール」で受信の規則にポート8787を追加

補足：

- サーバー役のパソコンのIPアドレスは**固定にしておく**（DHCPだと住所が変わってしまう）
- パソコンを再起動したら `pnpm start` を打ち直す必要がある。
  自動で立ち上がるようにする設定は、必要になったら足す
- 社外からも使いたい場合は、社内のパソコンではなくレンタルサーバー（VPS）に同じ手順で置く。
  そのときは通信の暗号化（HTTPS）も必要になるので、別途相談

### バックアップ

案件・図面・写真はすべて `data/` フォルダの中にある。
**このフォルダを丸ごとコピーすれば、それがバックアップになる。**
定期的に外付けディスクやNASにコピーしておくとよい。

## 3. デスクトップ版（アプリとして入れる）

ブラウザで足りていれば、ここは飛ばしてよい。
アプリにすると、ドックやスタートメニューから起動でき、印刷やPDF書き出しがメニューから使える。

### インストーラを作る

**使うOSと同じOSで作る必要がある**（macのアプリはmacで、Windowsのアプリは
Windowsで作る）。上の **1-3.** まで済ませたフォルダで：

```sh
pnpm dist:mac    # macOSで実行 → apps/desktop/release/ に .dmg ができる
pnpm dist:win    # Windowsで実行 → apps/desktop/release/ に .exe（インストーラ）ができる
```

### 配って入れる

できた `.dmg` / `.exe` を社内で配り、それぞれのパソコンで開く。

- **macOS**：dmgを開き、アプリをアプリケーションフォルダにドラッグ
- **Windows**：exeを実行し、案内どおりに進む

初回起動時に「接続先のサーバーの住所」を聞かれるので、**2.** で控えた
`http://192.168.x.x:8787` を入れる。あとから「ファイル → 接続先を変える」で変更できる。

### 初回だけ出る警告（署名していないため）

- **macOS**：「開発元を確認できないため開けません」と出る。
  → システム設定 → プライバシーとセキュリティ を開き、下の方の「このまま開く」を押す。
  2回目からは普通に開く
- **Windows**：「WindowsによってPCが保護されました」と出る。
  → 「詳細情報」→「実行」を押す

これは「誰が作ったアプリか、OSが確認できない」という意味の警告で、
アプリが壊れているわけではない。次の **4.** を読んでほしい。

## 4. コード署名について

### そもそも何なのか

コード署名とは、アプリに「**これは確かに○○が作ったもので、配る途中で中身が
すり替えられていない**」という電子的な封印を付けること。
macOSもWindowsも、起動時にこの封印を確認する。

封印がないと「誰が作ったかわからないアプリ」として扱われ、上に書いた警告が出る。
**アプリの中身の良し悪しとは関係ない。**警告を消すには、証明書を買って封印を付ける必要がある。

### 今どうするか（おすすめ）

**当面は署名しなくてよい。** 理由は3つ。

1. 社内の数名だけで使うので、初回に1回警告を通すだけで済む
2. そもそも**ブラウザで使えば警告は一切出ない**（アプリを配らないので署名が要らない）
3. 証明書は年額で費用がかかり、更新の手間も毎年ある

「外部の協力会社にも配る」「毎回警告が出るのが面倒」となった段階で考えれば十分。

### 実際に署名する場合（将来）

#### macOS

- **Apple Developer Program** に登録する。**年額 99米ドル**（1万数千円）
- 登録後に「Developer ID Application」証明書を作る
- 署名に加えて **公証（notarization）** というAppleへの登録作業も要る。
  これをやると警告が完全に出なくなる
- electron-builder が対応しているので、証明書とApple IDを環境変数で渡せば
  `pnpm dist:mac` のときに自動でやってくれる（設定は必要になったときに書く）

#### Windows

- **コード署名証明書**を認証局（DigiCert、SSL.com、GlobalSignなど）から買う。
  年額でおおむね**数万円**。価格は認証局と年数でかなり差がある
- 2023年6月から、証明書の鍵を**専用のUSBトークンかクラウドHSMに保管することが必須**に
  なったため、以前より手間と費用がかかるようになっている
- 普通の証明書（OV）でも、配り始めはSmartScreenの警告がしばらく出続けることがある。
  すぐ消したい場合は**EV証明書**（さらに高い）が要る

#### 費用の目安まとめ

| | 費用 | 効果 |
|---|---|---|
| 署名しない | 0円 | 初回だけ警告。社内配布なら実害は小さい |
| macだけ署名＋公証 | 年 約1.5万円 | macの警告が完全に消える |
| Windowsも署名 | 年 数万円＋トークン | Windowsの警告が（EVなら即座に）消える |

**まずは署名なしで社内配布 → 必要になったらmacだけ署名**、という順番をおすすめする。

### 署名の準備ができたら

証明書を用意できたら、`apps/desktop/electron-builder.yml` に設定を足すだけで済む。
そのときに教えてもらえれば書く。
