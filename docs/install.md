# 導入手順

このアプリは「**サーバー1台**」と「**それを見る画面**」でできている。
画面はブラウザでもデスクトップアプリでも同じものが出る。まずはブラウザで動かすのが一番早い。
ブラウザで開いたものは、そのまま**アプリのようにデスクトップから起動できる**（→ 3-1.）。

---

## 1. まず自分のパソコン1台で試す

### 1-1. Node.js を入れる

<https://nodejs.org/ja> から **LTS版（22以上）** をダウンロードして、案内どおりに入れる。
入ったか確認する（macOSは「ターミナル」、Windowsは「PowerShell」を開いて）：

```sh
node -v
```

`v22.x.x` 以上と出ればよい。

### 1-2. pnpm を使えるようにする

```sh
corepack enable
```

（Windowsで「アクセスが拒否されました」と出たら、PowerShellを**管理者として実行**して同じコマンドを打つ）

### 1-3. アプリのファイルを持ってくる

```sh
git clone https://github.com/takayukiokushin/zumen.git
cd zumen
pnpm install
```

Gitを使っていなければ、GitHubのページの緑色の「Code」→「Download ZIP」で落として展開し、
そのフォルダで `pnpm install` でもよい。

### 1-4. Claude APIキーを置く

`.env.example` をコピーして `.env` という名前にし、キーを書く。

```sh
cp .env.example .env
```

`.env` をメモ帳などで開いて、`ANTHROPIC_API_KEY=sk-ant-...` の部分を実際のキーに書き換える。
**このファイルはサーバーの中だけに置き、他の人には配らない。**
キーは <https://console.anthropic.com/> で発行する。

> キーがなくても、ヒアリングから図面を作る機能は動く。
> 使えなくなるのは「手書きメモの読み取り（AI解析）」だけ。

### 1-5. 利用者を登録する

```sh
pnpm --filter @zumen/server user:add jimu 事務担当 好きなパスワード
```

`jimu` がログインID。人数分くり返す。

### 1-6. 起動する

フォルダの中にある起動用のファイルを**ダブルクリック**する。

- macOS：`start-server.command`
- Windows：`start-server.bat`

黒い画面が開き、`サーバーを起動しました: http://127.0.0.1:8787` と出たら、
ブラウザでその住所を開く。さきほどのIDとパスワードでログインすれば使える。

ターミナルから起動してもよい。

```sh
pnpm start
```

止めるときは、その黒い画面で `Ctrl + C` を押すか、ウィンドウを閉じる。

> **この画面は開いたままにしておく。** 閉じるとサーバーが止まり、
> アプリからつながらなくなる。

## 2. 社内のみんなで使う

**1台をサーバー役にして、他のパソコンはブラウザでそこを見る**のが一番手間がかからない。
データ（案件・図面・写真）はサーバー役の1台にまとまるので、誰がどこで開いても同じものが見える。

1. いつも電源が入っているパソコンを1台決め、上の **1.** をそこで行う
2. `pnpm start` したときに表示される
   `社内の他のパソコンからは: http://192.168.x.x:8787` の住所を控える
3. 他のパソコン・iPad・スマホのブラウザでその住所を開く（同じ社内ネットワークにいること）
4. つながらない場合はサーバー役のパソコンのファイアウォールで **8787番ポート** を通す
   - macOS：システム設定 → ネットワーク → ファイアウォール → オプション で Node を許可
   - Windows：「Windows Defender ファイアウォール」で受信の規則にポート8787を追加

補足：

- サーバー役のパソコンのIPアドレスは**固定にしておく**（DHCPだと住所が変わってしまう）
- パソコンを再起動したら、`start-server` をもう一度ダブルクリックする必要がある
  （自動で立ち上がるようにする設定は、必要になったら足す）
- 社外からも使いたい場合は、社内のパソコンではなくレンタルサーバー（VPS）に同じ手順で置く。
  そのときは通信の暗号化（HTTPS）も必要になるので、別途相談

### バックアップ（ドロップボックスなどに自動で控えを取る）

案件・図面・写真はすべて、サーバー役のパソコンの `data/` フォルダに入っている。
**このパソコンが壊れると全部なくなる**ので、控えを取っておく。

`.env` に**保存先を1行書いておくだけ**でよい。
ドロップボックス（Google ドライブ・OneDrive でも同じ）のフォルダを指定すれば、
そのままクラウドに上がる。

```sh
# .env に足す。フォルダは無ければ自動で作られる
BACKUP_DIR=/Users/ユーザー名/Dropbox/単線結線図_控え
```

Windowsなら次のように書く（`\` ではなく `/` で書く）。

```sh
BACKUP_DIR=C:/Users/ユーザー名/Dropbox/単線結線図_控え
```

これで、サーバーを起動したときと**1日1回**、控えが作られる。

- `20260918-143205` のように日時の名前のフォルダができ、その中に
  案件のデータ（`zumen.db`）と現地写真（`files/`）が入る
- **30世代**まで残り、古いものから自動で消える
- 使用中でも安全な写し方をしているので、誰かが編集している最中でも壊れない

好きなときに手で取ることもできる。

```sh
pnpm --filter @zumen/server backup "/Users/ユーザー名/Dropbox/単線結線図_控え"
```

戻すときは、控えの中の `zumen.db` と `files/` を `data/` に上書きコピーする
（サーバーを止めてから行う）。

> **注意：`data/` フォルダそのものをドロップボックスの中に置くのはやめる。**
> 書き込んでいる最中に同期がかかると、データが壊れることがある。
> 上のやり方（控えだけをドロップボックスに置く）なら安全。

### パソコンにログインしたら自動で立ち上げる

毎回ダブルクリックするのが面倒なら、自動起動にできる。**設定用のファイルを
ダブルクリックするだけ**でよい。

- macOS：`install-autostart.command`
- Windows：`install-autostart.bat`

これで、**そのパソコンにログイン（サインイン）したときに**サーバーが自動で立ち上がる。
macOSの場合は、何かの拍子に止まっても自動でやり直す。

やめるときは `uninstall-autostart.command` / `uninstall-autostart.bat` をダブルクリックする。

注意：

- 立ち上がるのは**ログインしたとき**。パソコンの電源を入れてログイン画面で
  止まっている間は動かない。自動ログインにしておくと確実
- サーバー役のパソコンの電源を切ると、他の人も使えなくなる
- macOSでうまくいかないときは `data/server.log` に理由が残っている

## 3. アプリのように使う

**インストーラを配らなくても、アプリと同じように使える。**
やり方は2つあり、上のほうが手軽。

> **前提：アプリのアイコンを押しても、サーバーは立ち上がらない。**
> アイコンが開くのは「画面」だけで、案件を保管しているサーバーは別に動いている必要がある。
> サーバー役のパソコンで `start-server` をダブルクリックして、その画面を開いたままにしておく
> （パソコンを再起動したら、もう一度ダブルクリックする）。

### 3-1. ブラウザから「アプリとして入れる」（おすすめ）

Chrome か Edge で **2.** の住所を開き、右上の「︙」メニューから

- Chrome：**キャスト、保存、共有 → ページをアプリとしてインストール**
  （見当たらなければ「ショートカットを作成」→「ウィンドウとして開く」にチェック）
- Edge：**アプリ → このサイトをアプリとしてインストール**

これで、デスクトップ・ドック・スタートメニューに「単結」のアイコンが並ぶ。
押すとアドレスバーのない専用ウィンドウで開くので、見た目も使い勝手も普通のアプリと変わらない。

- **インストーラを作る必要がない**（配布も更新も不要）
- **警告が一切出ない**（アプリを配っていないので署名の話が関係しない）
- 画面を直したら、次に開いたときには新しくなっている
- iPad・iPhone は Safari の「共有 → ホーム画面に追加」で同じことができる

> 補足：社内の住所（`http://…`）で開いた場合、Chromeのメニュー名が
> 「ページをアプリとしてインストール」ではなく「ショートカットを作成」になることがある。
> どちらでも結果は同じ（ウィンドウとして開くにチェックを入れる）。

### 3-2. Electron版のインストーラを作る

ドックのアイコンに加えて、**メニューからの印刷・PDF書き出し**が使えるようになる。
ブラウザ版で足りていれば作らなくてよい。

**使うOSと同じOSで作る必要がある**（macのアプリはmacで、Windowsのアプリは
Windowsで作る）。上の **1-3.** まで済ませたフォルダで：

```sh
pnpm dist:mac    # macOSで実行 → apps/desktop/release/ に .dmg ができる
pnpm dist:win    # Windowsで実行 → apps/desktop/release/ に .exe（インストーラ）ができる
```

できた `.dmg` / `.exe` を社内で配り、それぞれのパソコンで開く。

- **macOS**：dmgを開き、アプリをアプリケーションフォルダにドラッグ
- **Windows**：exeを実行し、案内どおりに進む

初回起動時に「接続先のサーバーの住所」を聞かれるので、**2.** で控えた
`http://192.168.x.x:8787` を入れる。あとから「ファイル → 接続先を変える」で変更できる。

#### 初回だけ出る警告

署名していないため、初回に一度だけ警告が出る。

- **macOS**：「開発元を確認できないため開けません」
  → システム設定 → プライバシーとセキュリティ → 下の方の「このまま開く」
- **Windows**：「WindowsによってPCが保護されました」
  → 「詳細情報」→「実行」

2回目からは普通に開く。次の **4.** も読んでほしい。

## 4. Mac と Windows の混在について

**混在して問題ない。** 案件・回答・図面・現地写真は**すべてサーバー1台の中にある**ので、
どのパソコンから開いても同じものが見える。

- Macで作りかけた図面を、そのままWindowsで開いて続きを描ける（逆も同じ）
- 「Macで保存したファイルがWindowsで開けない」ということは起きない。
  そもそも各パソコンにファイルが保存されない
- PDFに書き出したあとも、元の図面はサーバーに残っているので、後から修正して出し直せる
  （PDFを読み直す必要はない）

パソコンごとに保存されるのは「デスクトップ版の接続先の住所」と
「ウィンドウの大きさ」だけで、図面のデータは入っていない。

## 5. 同じ案件を2人が開いたとき

**同時に編集することはできない。** 先に開いた人が編集でき、後から開いた人は
**閲覧のみ**になる（画面の上に「○○さんが編集中です」と出る）。
あとから保存したほうで上書きされてしまうのを防ぐためのしくみ。

- 編集していた人が案件を閉じる（別の案件に移る・ブラウザを閉じる）と、すぐに空く
- パソコンごと落ちてしまった場合でも、**3分ほどで自動的に空く**
- 急ぐときは「編集を引き継ぐ」を押せば奪える。
  ただし相手が保存していない分は失われるので、ひと声かけてから押すこと
- 案件の一覧にも「○○さんが編集中」と出るので、開く前に分かる

## 6. コード署名について

**今は不要。社内で使うだけなら署名しなくてよい。**

コード署名とは、アプリに「これは確かに○○が作ったもので、配る途中で中身が
すり替えられていない」という電子的な封印を付けること。
アプリをインストールするときに出る「開発元が不明です」という類の警告は、
この封印がないために出る。**アプリの中身の良し悪しとは関係ない。**

署名しない場合の影響は、**3-2.** の初回の警告だけ。
**3-1.**（ブラウザからアプリとして入れる）ならその警告も出ない。

将来、社外に配ったり販売したりすることになったら、そのときに対応すればよい。
参考までに費用の目安は、macOSが Apple Developer Program の年額99米ドル（1万数千円）、
Windowsがコード署名証明書で年額数万円＋鍵を保管する専用USBトークン。
証明書を用意できたら `apps/desktop/electron-builder.yml` に設定を足すだけで済む。
