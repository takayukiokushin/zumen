# APIキーの設定手順（管理者・事務担当向け）

単線結線図作成アプリで、**手書きメモの写真を読み取る機能**を使えるようにするための手順書。
専門知識は要りません。書いてあるとおりに進めてください。

---

## 1. これは何の話か

このアプリには2つの使い方があります。

| | 内容 | この手順が要るか |
|---|---|---|
| ① | 質問に答えていくと、図面のたたき台ができる | **要りません**（すでに使えます） |
| ② | 現地で書いた**手書きメモの写真**を読み込ませると、質問の答えが自動で埋まる | **この手順が要ります** |

②には Claude（クロード）というAIを使います。
その利用料を払うために、**「APIキー」という利用券**を1本つくって、
アプリに持たせる必要があります。これがこの手順書の目的です。

> **この手順をやらなくても、①は普通に使えます。**
> 急ぐ必要はありません。

---

## 2. 誰が何をするか

| 役割 | やること | 所要 |
|---|---|---|
| **管理者** | 利用券を1本つくって、事務担当に渡す | 5分 |
| **事務担当** | 受け取った利用券をアプリに設定して、動くか確かめる | 5分 |

支払い（会社のクレジットカード登録）は**すでに済んでいる前提**です。
まだの場合は、管理者が先に済ませてください（→ 6章）。

---

## 3. 管理者がやること

### 3-1. 管理画面を開く

<https://platform.claude.com/settings/keys> を開き、
**会社のカードを登録したアカウント**でログインします。

> この画面は英語です。慌てずに、押すボタンの名前だけ見てください。

### 3-2. 利用券をつくる

1. **「Create key」** というボタンを押します
2. 名前を聞かれるので、`単線結線図アプリ` と入れます
3. 作成を確定します

### 3-3. 文字列を控える

`sk-ant-` で始まる長い文字列が表示されます。これが利用券です。

> ⚠️ **この文字列は、この一度しか表示されません。**
> 画面を閉じると二度と見られません。必ずコピーして控えてください。
> （万一なくしても、同じ手順で作り直せます。古いほうは消してください）

### 3-4. 事務担当に渡す

控えた文字列を事務担当に渡します。

**渡し方のおすすめ**：事務担当のパソコンの前で、管理者が直接貼り付ける。
難しければ社内のチャットやメールでも構いませんが、**社外には絶対に出さないでください。**
これは会社の支払いに直結する文字列です。

### 3-5. 残高（クレジット）を買う ← **これが要ります**

<https://platform.claude.com/settings/billing> を開き、**残高を購入**します。

> ⚠️ **クレジットカードを登録しただけでは使えません。**
> Claude API は**前払いの残高から引かれる仕組み**で、残高が0だと
> 「credit balance is too low」と言われて動きません。
> 最低額（10米ドル程度）で構いません。

「自動チャージ（Auto reload）」を入れておくと、残高が切れて止まることがなくなります。

### 3-6. 使いすぎの歯止めをかけておく（おすすめ）

<https://platform.claude.com/settings/billing> を開き、
**「Spend limits」**（利用上限）という欄で上限額を決めます。

**$10（約1,500円）／月** に設定しておけば、それ以上は自動で止まります。
請求が膨らむ心配がなくなるので、最初は低めに設定しておくことをおすすめします。

## 4. 事務担当がやること

### 4-1. アプリのフォルダを開く

`test-windows.bat` や `start-server.bat` が入っているフォルダを開きます。

### 4-2. 設定ファイルをつくる

`.env.example` というファイルを探します。

1. そのファイルを**右クリック** →「**コピー**」
2. 同じ場所で**右クリック** →「**貼り付け**」
3. できた `.env.example - コピー` を**右クリック** →「**名前の変更**」
4. 名前を **`.env`** にする（先頭の点を忘れずに）
5. 「拡張子を変更すると…」と聞かれたら「**はい**」

> **メモ帳で「新規作成」してはいけません。**
> メモ帳は勝手に `.env.txt` という名前にしてしまい、アプリが見つけられなくなります。
> 必ず上のコピー＆名前変更でつくってください。

### 4-3. 利用券を書き込む

1. `.env` を**右クリック** →「**プログラムから開く**」→「**メモ帳**」
2. 次の行を探します

   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

3. `=` の右側を、管理者からもらった文字列に**まるごと置き換え**ます

   ```
   ANTHROPIC_API_KEY=sk-ant-api03-AbCdEf...（もらった文字列）
   ```

4. 上書き保存して閉じます

> `=` の前後に空白を入れないでください。
> 引用符（`"` や `'`）でくくる必要もありません。

### 4-4. ちゃんと使えるか確かめる

フォルダの中で何もないところを**右クリック** →
「**ターミナルで開く**」（または「PowerShell ウィンドウをここに開く」）を選び、
次の1行を貼り付けて Enter を押します。

```
pnpm --filter @zumen/server apikey
```

こう出れば**成功**です。

```
利用券: sk-ant-api0…aB3x（108文字）
つながるか試しています…

✓ 利用券は使えます。
  返事: 使えます
  かかった時間: 1.8秒
  使った分量: 入力28 / 出力5トークン
  この1回の金額: 約$0.0003（1円未満）
```

**この確認にかかるお金は1円未満です。** 何度やっても構いません。

うまくいかない場合は、画面に理由と次にやることが出ます（→ 5章）。

### 4-5. アプリを起動し直す

1. 黒い画面（サーバー）が開いていれば、**閉じます**
2. `start-server.bat` を**ダブルクリック**します
3. ブラウザでアプリを開き、**「スケッチ読み取り」**のタブを見ます

赤い案内（「この機能は、まだ使えるようになっていません」）が**消えていれば完了**です。

## 5. うまくいかないとき

画面に出た言葉で探してください。

| 画面に出ること | 原因 | どうするか |
|---|---|---|
| 利用券（ANTHROPIC_API_KEY）が設定されていません | `.env` が無い、または名前が違う | ファイル名が `.env.txt` になっていないか確かめる（4-2） |
| 利用券が受け付けられませんでした（認証エラー） | 文字列の貼り間違い | 途中で切れていないか、前後に空白が入っていないか確かめる |
| この利用券には、この操作をする権限がありません | 権限不足 | 管理者に、役割を「Developer」以上にしてもらう |
| 利用上限に達しているか、混み合っています | 上限に達した | 管理者に Spend limits を確かめてもらう（3-6） |
| 利用券は正しいのですが、アカウントの残高がありません | 残高が0 | 管理者に残高を購入してもらう（3-5）。カード登録だけでは使えない |
| つながりませんでした（通信エラー） | ネットワーク | インターネットにつながっているか確認。社内で通信が止められている場合は情報システム担当へ |
| `pnpm` は認識されていません | 準備が未了 | 先に `test-windows.bat` を一度実行する |

**それでも直らないときは、画面に出ている文字をそのままコピーして相談してください。**
スクリーンショットでも構いません。

## 6. 支払いがまだ済んでいない場合（管理者向け）

<https://platform.claude.com/settings/billing> を開き、
会社のクレジットカードを登録します。登録後、3章に進んでください。

月額の固定費はかかりません。**使った分だけ**の支払いです。

## 7. よくある質問

**Q. 月にいくらかかりますか**
手書きメモ1枚あたり20〜30円程度の見込みです。月に数十件使って数百円〜千円程度。
固定費はありません。**実際の金額は、使うたびにアプリの画面（黒い画面）に表示されます。**

**Q. 使いすぎが怖いのですが**
上限額を設定できます（3-5）。超えると自動で止まるだけで、請求は上限で止まります。

**Q. この利用券で、何の情報が外に出るのですか**
読み取らせた**現地メモの写真だけ**です。顧客名簿や図面一式が送られることはありません。

**Q. 利用券は社員全員に配るのですか**
いいえ。**サーバー役のパソコン1台にだけ**置きます。
他のパソコンやブラウザには一切配りません。

**Q. 担当者が変わったらどうしますか**
利用券はそのまま使えます。心配なら、古い利用券を消して新しく作り直してください
（3章と同じ手順）。

**Q. やめたくなったら**
管理画面で利用券を消せば止まります。使わなければ請求も発生しません。

## 8. 言葉の対応

技術的な言い方をこの手順書では言い換えています。

| この手順書 | ほかで見かける言い方 |
|---|---|
| 利用券 | APIキー、APIトークン、`ANTHROPIC_API_KEY` |
| 管理画面 | Claude Console、platform.claude.com |
| 設定ファイル | `.env`（ドットエンブ） |
| 黒い画面 | ターミナル、コマンドプロンプト、PowerShell |
| サーバー役のパソコン | 案件を保管している1台。これが動いている間だけアプリが使える |
