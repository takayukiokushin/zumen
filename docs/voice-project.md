# 音声入力から図面を作る：Claude のプロジェクトの用意と使い方

現地で、Claude のアプリに声で設備を話すと、Claude が「アプリ用の文章」を出します。
それをアプリの「**音声入力から作成**」に貼り付けると、確認画面を通して、図面のもとになる答えが入ります。

- アプリは、AI を呼びません（APIキーも要りません）。貼り付けた文章を読むだけです。
- **お客様名称・事業場名称・図面名称は、声で話しません。** アプリの「設備を入力して作成」で、手で入力します（情報漏えいを防ぐため）。
  Claude の指示文にも載せていません。万一、貼り付けた文章に入っていても、アプリは取り込みません。
- 読み取った内容は、そのまま図面には入りません。確認画面で、人が見て、選んで、反映します。

## 1．プロジェクトを作る（最初の1回だけ・管理する人）

画面の名前は、Claude の更新で変わることがあります。そのときは、近い名前のものを選んでください。

1. Claude のアプリ（またはブラウザ）で、**プロジェクト**を新しく作ります。
   - 名前の例：`単線結線図（音声入力）`
   - 説明の例：`現地で声で話した設備の内容を、単線結線図作成アプリに入れる文章にまとめるプロジェクトです。お客様名称は話しません。`
2. プロジェクトの**指示**（カスタム指示）に、アプリの「音声入力から作成」の画面にある **「Claude用の指示文をコピー」**で取った文章を、貼り付けます。
   - 同じ内容が、リポジトリの `docs/claude-voice-instruction.txt` にも置いてあります（約3万9千文字。1つの文章です）。
3. プロジェクトを、会社のメンバーに**共有**します（Team プランの、プロジェクトの共有）。全員が、同じ指示で使えます。

## 2．現地での使い方

1. Claude のアプリで、このプロジェクトを開き、**音声入力**（マイクのボタン）で話しかけます。
   - 引込元の電柱から順に、分かるところから、**つらつらと話し続けて**かまいません。句読点が無くても、専門用語が聞き間違えられても（「区分解兵器」など）、Claude が直します。
   - **お客様名称・事業場名称などは、話さないでください。**（話しても、記録されません）
2. 話し終えて送ると、Claude が、聞き取った内容を2〜5行で読み返し、**話されていなかった大事なことだけ、まとめて1回だけ**聞き返します。
   聞かれるのは、次の6つだけです（話していれば聞かれません）：
   引込元（電柱 / 地上キャビネット）・区分開閉器（PAS / PGS / UGS / なし）・主遮断装置の形式（CB形 / PFS形）・変圧器の台数・受電設備エリアの数・自信が持てない大事な数字。
   - 定格（電圧・電流）やケーブルの太さなどの細かいことは、聞かれません。あとで、アプリで入力します。
   - 聞き返しに答えます（「分かりません」「そのままで」でもかまいません）。**答えると（または答えなくても）、自動で、アプリ用のコードブロックが出ます。**「ここまでです」と言う必要はありません。
   - すべて話してあれば、聞き返さずに、すぐ、コードブロックが出ます。
3. 出てきた**コードブロック**（`json` と書かれた枠）の、右上の**コピー**ボタンでコピーします。
4. アプリの「**音声入力から作成**」を開き、枠に貼り付けて、「読み取る」を押します。
5. 確認画面で、読み取った内容と、話された言葉を見比べます。自信がないと書かれたもの（黄色）は、よく見ます。反映するものにチェックを入れて、反映します。
6. 「設備を入力して作成」の画面で、**お客様名称・事業場名称を手で入力**します。声で話さなかった細かい項目（定格など）も、ここで入力します。
7. 「図面」で、図面を確かめて、保存します。

## 3．アプリが「取り込めない」と言ったとき

- **「Claudeの出力に、アプリ用のデータが含まれていません」と出たとき：** Claude が、聞き返しだけを返している（まだ答えていない）か、コードブロックの外の文章だけを貼っている可能性があります。
  Claude に「**アプリ用のコードブロックで出してください**」と伝えて、出てきたコードブロックを貼り直します。
- **「アプリ用のデータの形（"answers"）が見つかりませんでした」と出たとき：** Claude に「アプリ用のコードブロックを、指示文の見本の形で出してください」と伝えます。
- **「アプリ用の目印（"format"）がありません」「古い（または別の）指示文で作られた可能性があります」と出たとき：** 内容は取り込まれていますが、Claude のプロジェクトの指示が、古い・途中までしか入っていない可能性があります。
  アプリの「音声入力から作成」の下の方の**「Claude用の指示文をコピー」**で、新しい指示文を取り、プロジェクトの指示を**入れ替え**ます（画面の「指示文書のバージョン」と、Claude が出した文章の `"version"` が同じになります）。
- **「アプリにない項目です」「選べない値「○○」です」と出たとき：** そのまま、Claude に「次の項目は取り込めませんでした。…」と伝えて、直した文章を出してもらいます。

## 4．アプリの質問を増やしたとき（開発する人）

1. `pnpm voice` を実行して、`docs/claude-voice-*.txt` を作り直します（忘れていると、`pnpm check` が止まります）。
2. 版の記号が変わるので、Claude のプロジェクトの指示文を、新しいものに入れ替えるよう、メンバーに伝えます。

## 5．試すときの確認

指示文の出来は、Claude のプロジェクトで、実際に話して、確かめます。次の点を見てください。

- 話し終えて送ったあと、Claude が、**読み返し（2〜5行）と、聞き返し（1回だけ・必ず確認する6つの範囲）**を、**1回の返事で**出すか。話したことは聞かれないか。
- 聞き返しに答えたあと（「分かりません」と答えても）、**もう聞き返さずに**、アプリ用の**コードブロック**が出るか。図・アーティファクト・ファイルを作っていないか。
- 全部話してあるとき、聞き返さずに、すぐ、コードブロックが出るか。
- 定格・ケーブルの太さなど、細かいことを聞かれないか。「分かっていない項目の一覧」を言われないか。
- お客様名称を話しても、聞き返さず、記録せず、読み返しにも出てこないか。
- 専門用語の聞き間違い（「ブイシーティー」「区分解兵器」など）が、正しい用語に直るか。
- 「根拠」（evidence）が、自信がない項目だけに付いているか。
- 出した文章を、アプリが「取り込めない」と言わずに、**最初の貼り付けで**読み取れるか。取り込めなかった項目が出たら、その内容（Claude の返事と、アプリのメッセージ）を、開発する人に伝える。
