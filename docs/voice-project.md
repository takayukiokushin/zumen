# 音声入力から図面を作る：Claude のプロジェクトの用意と使い方

現地で、Claude のアプリに声で設備を話すと、Claude が「アプリ用の文章」を出します。
それをアプリの「**音声入力から作成**」に貼り付けると、確認画面を通して、図面のもとになる答えが入ります。

- アプリは、AI を呼びません（APIキーも要りません）。貼り付けた文章を読むだけです。
- **お客様名称・事業場名称・図面名称は、声で話しません。** アプリの「設備を入力して作成」で、手で入力します（情報漏えいを防ぐため）。
  Claude の指示文にも載せていません。万一、貼り付けた文章に入っていても、アプリは取り込みません。
- 読み取った内容は、そのまま図面には入りません。確認画面で、人が見て、選んで、反映します。

## 1．プロジェクトを作る（最初の1回だけ・管理する人）

画面の名前は、Claude の更新で変わることがあります。そのときは、近い名前のものを選んでください。

1. Claude のアプリ（またはブラウザ）で、**プロジェクト**を新しく作ります。
   - 名前の例：`単線結線図（音声入力）`
   - 説明の例：`現地で声で話した設備の内容を、単線結線図作成アプリに入れる文章にまとめるプロジェクトです。お客様名称は話しません。`
2. プロジェクトの**指示**（カスタム指示）に、アプリの「音声入力から作成」の画面にある **「Claude用の指示文をコピー」**で取った文章を、貼り付けます。
   - 同じ内容が、リポジトリの `docs/claude-voice-instruction.txt` にも置いてあります。
3. プロジェクトを、会社のメンバーに**共有**します（Team プランの、プロジェクトの共有）。全員が、同じ指示で使えます。

## 2．現地での使い方

1. Claude のアプリで、このプロジェクトを開き、**音声入力**（マイクのボタン）で話しかけます。
   - 引込元の電柱から順に、分かるところから、**つらつらと話し続けて**かまいません。途中で Claude が質問することはありません（「はい、続けてください」と返すだけです）。
   - **お客様名称などは、話さないでください。**（話しても、記録されません）
2. 話し終えたら、「**ここまでです**」と言います。Claude が、聞き取った内容を3〜6行で読み返します。
   - そのあと、**話されていなかった大事なことだけ**、まとめて1回、聞き返されます。聞かれるのは、次の6つだけです（話していれば聞かれません）。
     引込元（電柱 / 地上キャビネット）・区分開閉器（PAS / PGS / UGS / なし）・主遮断装置の形式（CB形 / PFS形）・変圧器の台数・受電設備エリアの数・聞き取りに自信がない重要な数字（変圧器の容量・台数）
   - 定格（電圧・電流）やケーブルの太さなどの細かいことは、聞かれません。あとで、アプリで入力します。
   - 答えると、自動で、アプリ用の文章が出ます。
3. 出てきた**コードブロック**（`json` と書かれた枠）の、右上の**コピー**ボタンでコピーします。
4. アプリの「**音声入力から作成**」を開き、枠に貼り付けて、「読み取る」を押します。
5. 確認画面で、読み取った内容と、話された言葉を見比べます。自信がないと書かれたもの（黄色）は、よく見ます。反映するものにチェックを入れて、「反映」を押します。
6. 「設備を入力して作成」の画面で、**お客様名称・事業場名称を手で入力**します。声で話さなかった細かい項目（定格など）も、ここで入力して、図面を仕上げます。
7. 「図面」で、図面を確かめて、保存します。

## 3．アプリが「取り込めない」と言ったとき

- **「アプリにない項目です」「選べない値です」と出たとき：** そのまま、Claude に「次の項目は取り込めませんでした。…」と伝えて、直した文章を、もう一度出してもらいます。
- **「古い指示文で作られた可能性があります」と出たとき：** アプリで質問が増えたあとに、Claude のプロジェクトの指示文を、入れ直していません。
  アプリの「音声入力から作成」の下の方の**「Claude用の指示文をコピー」**で、新しい指示文を取り、プロジェクトの指示を**入れ替え**ます（版の記号が変わります）。
- **「アプリ用のJSONが見つかりません」と出たとき：** コードブロックの中身（`{` で始まる文章）を、もれなく、コピーして貼り付けたか確認します。

## 4．アプリの質問を増やしたとき（開発する人）

1. `pnpm voice` を実行して、`docs/claude-voice-*.txt` を作り直します（忘れていると、`pnpm check` が止まります）。
2. 版の記号が変わるので、Claude のプロジェクトの指示文を、新しいものに入れ替えるよう、メンバーに伝えます。

## 5．試すときの確認

指示文の出来は、Claude のプロジェクトで、実際に話して、確かめます。次の点を見てください。

- 話している途中で、Claude が質問せず、「はい、続けてください」だけ返すか。
- 「ここまで」のあと、3〜6行で読み返し、聞き返しが**1回だけ**、**必ず確認する6つ**の範囲か（話したことは聞かれないか）。
- 定格・ケーブルの太さなど、細かいことを聞かれないか。「分かっていない項目の一覧」を言われないか。
- お客様名称を話しても、聞き返さず、記録せず、読み返しにも出てこないか。
- 専門用語の聞き間違い（「ブイシーティー」など）が、正しい用語に直るか。
- 答えたあと、もう聞き返さずに、アプリ用の文章が出るか。
- 「根拠」（evidence）が、自信がない項目だけに付いているか。
- 出した文章を、アプリが「取り込めない」と言わずに読み取れるか。取り込めなかった項目が出たら、その内容（Claude の返事と、アプリのメッセージ）を、開発する人に伝える。
