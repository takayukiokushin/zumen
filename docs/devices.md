# 対応している端末（画面の大きさ）

2026-10-30 に、実際の画面で確認した結果。

| 端末 | 画面の幅の目安 | 使い心地 |
|---|---|---|
| **パソコン** | 1280px 以上 | すべての機能を、いちばん使いやすい形で使える |
| **タブレット**（縦・横） | 820〜1180px | **パソコンと同じ機能を、ほぼ同じ形で使える。** 図面の記号の移動・結線・拡大縮小（2本指）も、指でできる |
| **スマホ**（縦・横） | 390〜844px | 見る・入力する・声やスケッチから作る・保存・印刷は、使いやすい。図面の細かい編集は、できるが、小さい画面なので補助的な使い方を想定 |

## スマホで、見た目が変わるところ

- 上の帯は3段になる（名前／4つのタブ／右側のボタン）
- 図面一覧・消した案件・利用者の一覧は、1人（1件）を1枚のカードで表示する
- 「設備を入力して作成」は、入力欄が全幅の1列。「いまの構成」と「目次」は、ボタンで開く
- 図面の画面は、よく使うボタンだけを表に出す。ほかは「ほかの操作」、記号の一覧と選んだものの設定は「記号・設定」を押すと出る

## 指で図面を見る・動かす（タブレット・スマホ）

- 2本指でつまむ・広げる：縮小・拡大
- 2本指でなぞる、または、記号のない所を1本指でなぞる：画面を動かす
- 記号を1本指で動かす途中に、2本目の指を置く：動かしかけた記号は元に戻る（確定しない）
- ボタンや入力欄は、指で押す端末では、高さ44px以上

## 確認のしかた（開発する人）

ブラウザの開発者向け画面ではなく、`playwright` で、幅 390 / 844 / 820 / 1180 / 1280 / 1440 の6通りを開き、
全画面の「画面の外に出た部品」「必要な幅」「小さい操作部品」を測った。実際のタブレット・スマホでの確認は、これからお願いする
（指の太さや、画面の叩き方による違いは、実機で確かめるのが確実）。
