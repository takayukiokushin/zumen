# セキュリティの点検と、対応の記録

最終点検：2026-10-30。**点検したのは、このアプリのコードと通信の作りまで**。
会社のネットワーク・Mac の設定・Dropbox・Cloudflare の設定は、見ていない（下の「お願いしたいこと」に、確認してほしい点を書いた）。

## すでに入っていたもの

- パスワードは、読み取れない形（scrypt＋ソルト）で保存する
- ログインを10回まちがえると、そのIDを30分止める（総当たり対策）。存在しないIDでも同じ時間をかける
- ログインの印は、ランダムな長い文字列で、ブラウザのスクリプトからは読めない（HttpOnly）
- データベースへの問い合わせは、すべて「値を後から入れる形」（SQLインジェクションは通らない）
- 案件の読み書きは、そのつど、アカウントの種類（練習用・標準・管理用）を確かめている
- 画面に出す文字は、画面の仕組みが自動で無害にする。図面の文字は、記号を無害にして埋め込む
- Claude の APIキーは、サーバーの `.env` だけ。ブラウザには配らない

## 今回、直したもの（2026-10-30）

| 何が危なかったか | 直し方 |
|---|---|
| 現地写真として、**どんな種類のファイルでも**入れられ、入れた種類のまま返していた。ログインしている人が細工したファイルを入れ、他の人がそれを開くと、その人になりすました操作をされるおそれがあった | 写真の種類だけ受け付ける（SVG・HTML などは断る）。返すときも、中のスクリプトが動かない決まりを付ける |
| 画面に、「外のスクリプトを動かさない」「他のサイトに埋め込ませない」という、ブラウザへの決まりが付いていなかった | 全体に付けた（上のファイルの件や、図面への細工があっても、動かなくなる） |
| ログインの印が、データベースに**そのままの形**で入っていた。控え（Dropbox）が外に出ると、そこから他人になりすませた | ログインの印は、元に戻せない形（SHA-256）で保存する。**更新後、全員もう一度ログインが必要**（一度だけ） |
| 管理者がパスワードを変えても、すでに入っている人のログインが残っていた（パスワードを変える理由は、たいてい「知られたかも」） | パスワードを変えると、その人のログインが切れる（自分で変えたときは、いまの画面は残す） |

| でたらめなIDでログインを試され続けると、サーバーの記憶が増え続ける | 記録するIDの数に上限（5000）を付けた |

## 残っていること（判断が要る・運用で対応するもの）

1. **社内の http（`http://192.168.x.x:8787`）は、暗号化されていない。** 社内Wi-Fi（WPA2）でも、Wi-Fiのパスワードを知っている人は、同じWi-Fiの人の通信を、盗み見られる可能性がある。ログインのIDとパスワードが、そのまま見える。
   - 対応案：社内でも、**https の住所だけを使う**。そのうえで、サーバーを、社内から直接つなげない設定にする（案は、報告のときに）。
2. **外から入れるようにするなら、アプリのパスワードだけに頼らない。** Cloudflare の「Access」（メールで本人確認してから、アプリの画面に進ませる）を前に置くのが、いちばん効く。
3. **IDが推測されやすい。** `docs/setup-memo.md` の `zumen_kanri` などは、リポジトリ（いまは公開）に書いてある。IDが分かると、**わざとまちがえて、そのIDを止め続ける**（利用できなくする）ことができる。管理用のIDは、書いていない名前にすることを勧める。リポジトリの private 化は、外から入れるようにする前に済ませる。
4. **パスワードの強さ。** 10文字以上で、IDと同じ・IDを含むもの、よくある言葉、連番、同じ文字の繰り返しは断る（対応済み・2026-10-30）。すでに登録してあるパスワードは、変えるまで、そのまま使える。
5. **2段階認証は無い。** 外から入れるなら、2の Access で代わりになる。
6. **スケッチ読み取りの画像は、外部の AI（Anthropic）に送られる。** 画面に注意書きを出してある。画像の中の文章に、「AIへの命令」が書かれていても、結果は必ず人が確認してから反映する作りなので、勝手に図面が変わることはない。
7. `/api/health`（ログイン前でも見られる）は、利用者の人数・APIキーの有無・版を返す。大きな害は無いので、そのままにしてある。

## お願いしたいこと（会社の側で確認する点）

- サーバーの Mac：**FileVault（ディスクの暗号化）を入れる**、画面ロックを設定する、macOS を更新する（盗まれたとき、更新が遅れているとき）
- Dropbox は、**会社のアカウントで、2段階認証を入れる**。控えには、案件とログインの記録（パスワードは読み取れない形）が入る
- `.env`（APIキー）は、他の人が見られないフォルダに置く。必要なら `chmod 600 .env`
- Wi-Fi：来客用と社内用を分ける（できれば）。社内の Wi-Fi のパスワードは、退職者が出たら変える
