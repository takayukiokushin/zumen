# レイヤー（図面の種類）の使い方

停電範囲図・絶縁耐力試験範囲図など、**単線結線図の上に赤い印を重ねた図面**を作る機能です。
元の単線結線図は、そのままです。赤い印は、図面の種類（レイヤー）ごとに別々に持ちます。

## 1. 図面の種類を選ぶ

図面の画面の「向きと印刷」の欄に、**「図面の種類」**のリストがあります。

| 種類 | 説明 |
|---|---|
| 単線結線図 | ふつうの図面。図面を開くと、いつもここから始まります |
| 停電範囲図 | 印刷の表題の「図面名称」が「停電範囲図」になります |
| 絶縁耐力試験範囲図 | 同じく「絶縁耐力試験範囲図」になります |
| 追加したレイヤー | 3つまで。名前は自由に付けられ、あとから名前の変更・削除ができます（リストの一番下の「＋ レイヤーを追加」） |

- 表題の「事業場名」「お客様名」などは、どの種類でも同じです。変わるのは**図面名称の部分だけ**です。
- レイヤーを選んでいるあいだ、**元の図面は薄く表示され、動かせません**（誤って元の図面を動かさないため）。触れるのは、そのレイヤーに置いた赤い印だけです。
- 「操作を戻す」「操作を進める」は、**レイヤーごとに別々**です。
- 単線結線図を選んでいるときは、赤い印のボタンは薄く表示され、押すと「このレイヤーでは選択できません」と出ます。

## 2. 赤い印の置き方

「レイヤーの印」の欄のボタンで置きます。赤い印は、すべて**赤・少し太め**です（カラーで印刷してください）。
置いたものは、**近くの機器について動きます**。機器が動けば、赤い印も一緒に動きます。

| ボタン | 置き方 | 直し方 |
|---|---|---|
| メモを追加 | 図面の下に文字が出ます | 文字を書き換え、大きさ（記号の横の文字の1倍〜5倍）・太字を変える。ドラッグか矢印キーで動かす |
| ×印 | 開閉器（PAS・VCB・LBSなど）か、**母線（横の線）の付けたい位置**をクリック。もう一度クリックで外す。置く前に、置いたときの大きさが薄く出る | 右の欄で大きさ（小・中・大）。ドラッグか矢印キーで、開閉器の中央からずらせる。同じ開閉器に2つ以上付けられる |
| 接地 | **2回クリック**。1回目＝つなぐ場所（母線の途中・記号の接続点）、2回目＝マークを置く場所 | 先・根もとの丸をドラッグ。大きさ（中・大）、横棒あり／なし、左右反転、長さ、横の文字（番号・回路名） |
| 赤い枠 | **ドラッグ**で四角を描く。種類は停電範囲・充電範囲・印加範囲 | 線をつかんで動かす、8つの丸で大きさを変える。近くの文字（左上・右上・左下・右下）を書き換える。**斜線が入るのは充電範囲だけ** |
| 印加点 | 置きたい場所をクリック。母線の途中・記号の接続点の近くなら吸い付く（Alt キーを押すと吸い付かない） | ドラッグか矢印キーで動かす |
| 印加点の矢印 | 印加点をクリック（1つの点に1本）。文字は最初「印加点」 | 向き（8方向）・長さ・文字・大きさ・太字。尾の端の丸をドラッグしても変えられる |
| 渡り線 | 点を**順にクリック**（1つ目→2つ目で弧の線。続けて次の点をクリックすると、さらにつながる） | 弧の形（直線・ゆるい弧・普通の弧・すごく丸い弧）と、ふくらむ向きの反転を、1本ごとに |

- 置くのをやめるときは、**Esc キー**か、画面に出る「…を置き終わる」ボタンを押します。
- 置いたものは、クリックして選び、**Delete キー**か右の欄のボタンで外せます。点を外すと、その点を指す矢印・その点につないだ渡り線も外れます。
- **つないだ機器が無くなった**印（×印・接地・点・矢印・渡り線）は、画面にも印刷にも出なくなり、保存のときにデータからも外れます。
  文字と枠は消えずに、最後に置いた場所に残ります。

## 3. 数の上限

レイヤーごとに、**種類ごとに100個まで**です（メモ・×印・接地・枠・点・矢印・渡り線）。レイヤーは、固定の2つのほかに、追加は3つまでです。

## 4. 印刷・PDF化

「印刷プレビュー」「印刷実行 / PDF化」は、**いま選んでいる1種類だけ**です。向き（縦・横）も、レイヤーごとに決められます。
単線結線図に書いたメモは、どのレイヤーの印刷にも出ます（元の図面の一部だからです）。
元の図面（単線結線図）の印刷は、レイヤーを使っても、これまでと**1文字も変わりません**。

## 5. 元の図面が変わったとき

元の図面を動かした・ヒアリングの回答を変えて図面が作り直された、などで、レイヤーに手を入れたときの元の図面と違ってくると、そのレイヤーが**「要確認」**になります。

- レイヤーの一覧に「要確認」の印が付きます。
- そのレイヤーを選ぶと、一度だけポップアップで「図面が変わっています。図記号や文字の配置を確認してください」と出ます。
- 画面の上の帯は、**「確認した」を押すまで残ります**。赤い印が、元の図面の記号や文字に重なっていないか・ずれていないかを見て、よければ「確認した」を押してください。

## 6. 複製・保存について

- 図面の一覧の「複製して新規作成」では、**どのレイヤーも一緒に複製するか**を聞かれます（最初は、1つも選ばれていません）。
- レイヤーは、図面と一緒に保存されます。バージョンアップ前の古い画面から保存して、レイヤーが消えてしまうことは、サーバーが断って防ぎます。

## 7. 作る側のための、確認のしくみ（開発者向け）

- `pnpm check` の中の図面の検査（`scripts/check-drawing/part4〜11.ts`）が、レイヤーの各機能を確かめます。
- **見本の図面**：`docs/golden/L1〜L3` が、赤いレイヤーの印刷の見本です。赤い印の形・置き方・重なりを変えると、`pnpm check` が知らせます。
  意図して変えたときは、変わった図面を目で見て確かめてから、`pnpm golden` で保存し直します。
- `pnpm selftest` が、赤い印のすべての種類が、サーバーに保存して開いても、そのまま戻ることを確かめます。
