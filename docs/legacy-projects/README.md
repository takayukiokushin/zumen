# 古い形式の案件の見本

過去の版で保存された案件の形を、**そのまま**残したものです。
アプリを直したあとも、古い案件が、ふつうに開けて、手で直した内容が消えないことを、自動で確かめるために使います。

- **作り直さない・直さない。** 見本は、そのときの形を残すためのものです。アプリを変えて、見本が開けなくなったら、見本ではなくアプリを直します。
- **新しい形式に変えるとき（保存する形を変えたとき）は、変える前の形の見本を、1件足します。**
- 確かめるのは `pnpm check`（`scripts/check-legacy.ts`：図面の画面と同じ手順で開く）と、`pnpm selftest`（サーバーが受け取って返せる・複製できる）。

| ファイル | 内容 |
|---|---|
| 01-early-version.json | 最初のころの案件。区分開閉器の質問が無い／引込点の区分と名称が別々／OCGR／VT・CTは台数だけ／いまは無い回答が残っている |
| 02-two-areas-before-sendout.json | エリアが2か所以上。送り出しの開閉器・段・途中の機器が無かった時代 |
| 03-two-stages-before-parts.json | 送り出しが2段。途中の機器・継電器の質問が無かった時代 |
| 04-edited-drawing-old-format.json | 手で直した図面。自動で作った図面の控え・手で直した内容の記録・レイヤーが、まだ無かった時代 |
| 05-edited-drawing-current-format.json | 手で直した図面。控え・手で直した内容の記録・レイヤー（停電範囲図）が入っている形 |
| 06-broken-layers.json | レイヤーの中身が壊れている図面（開けて、壊れた部分だけが整理されること） |
| 07-retired-ocgr-symbol.json | 廃止したOCGRの記号（relay-ocgr）が入っている、手で直した図面。開くと、GRの記号になる（`RETIRED_SYMBOLS`） |

各ファイルは `{ name, era, answers, drawing }` の形です（`drawing` が null のものは、図面を手で直していない案件）。
