# APIキーの申請（管理者への説明文）

社内で Claude の利用券（APIキー）を発行する許可をもらうための文面。
そのままコピーして使える。金額は実績が出たら直すこと。

---

## 短い版（口頭・チャット向け）

```
単線結線図を作るアプリを社内向けに作っています。
現地で書いた手書きメモを写真で撮ると、図面のたたき台が
自動でできる、というものです。

このメモを読み取る部分に Anthropic 社のAIを使うので、
「APIキー」という利用者番号を発行したいです。許可をいただけますか。

・費用は使った分だけ。メモ1枚20〜30円、月に数百円〜千円程度の見込み
・月額の固定費なし。上限額も設定できる
・発行は console.anthropic.com で、会社のメールとカードを登録するだけ（5分）
・読み取らせるのは現地メモの写真だけ
・番号はアプリのサーバーにだけ置き、各パソコンには配りません
```

## 少し丁寧な版（メール向け）

```
お疲れさまです。

高圧受電設備の単線結線図を作るアプリを社内向けに作っています。
現地で書いた手書きメモを写真で撮って読み込ませると、
図面のたたき台が自動でできる、というものです。

この「手書きメモを読み取る」部分に、Anthropic 社のAIサービスを使います。
そのために「APIキー」という利用者番号のようなものを発行したいので、
許可をいただけないでしょうか。

■ いくらかかるか
　使った分だけの従量課金です。
　メモ1枚あたり20〜30円程度、月に数十件使って数百円〜千円程度の見込みです。
　月額の固定費はかかりません。上限額を設定することもできます。

■ 手続き
　https://console.anthropic.com/ で会社のメールアドレスと
　クレジットカードを登録すれば、その場で発行できます。5分程度です。

■ 情報の扱い
　読み取らせるのは現地メモの写真だけです。
　発行した番号はアプリのサーバーにだけ置き、社員の各パソコンには配りません。

■ 使わない場合どうなるか
　手書きメモの読み取りだけが使えなくなります。
　質問に答えて図面を作る機能はそのまま使えます。

よろしくお願いします。
```

---

## 聞かれそうなこと

| 質問 | 答え |
|---|---|
| 月いくら？ | 使った分だけ。月に数十件で数百円〜千円程度の見込み。固定費なし |
| 使いすぎが怖い | 管理画面で上限額を設定できる。超えると止まる |
| 情報は外に出ないか | 読み取らせるのは現地メモの写真だけ。顧客名簿や図面一式を送るわけではない |
| 無くても困らないか | 手書きメモの読み取りだけが使えなくなる。ほかの機能は全部使える |
| 解約は？ | いつでも止められる。使わなければ請求も発生しない |

## 補足（社内向けの事実）

- 実際の単価はまだ実測していない。見込み額は入力と出力の分量からの概算
- アプリは解析1件ごとに実際の使用量と概算額をログに出すので、
  数件試せば実単価が分かる。高ければより安いモデルに変えられる
- キーはサーバーの `.env` に置く。利用者の端末やブラウザには配らない
