# APIキーの申請（管理者への説明文）

社内で Claude の利用券（APIキー）を発行する許可をもらうための文面。
そのままコピーして使える。金額は実績が出たら直すこと。

---

## 短い版（口頭・チャット向け）

```
単線結線図を作るアプリを社内向けに作っています。
現地で書いた手書きメモを写真で撮ると、図面のたたき台が
自動でできる、というものです。

このメモを読み取る部分に Anthropic 社のAIを使うので、
「APIキー」という利用者番号を発行したいです。許可をいただけますか。

・費用は使った分だけ。メモ1枚20〜30円、月に数百円〜千円程度の見込み
・月額の固定費なし。上限額も設定できる
・発行は platform.claude.com で、会社のメールとカードを登録するだけ（5分）
・読み取らせるのは現地メモの写真だけ
・番号はアプリのサーバーにだけ置き、各パソコンには配りません
```

## 管理者にやってもらう作業

**管理者が必ずやる必要があるのは「支払い方法の登録」だけ。**
それ以外は作る側でできる。やり方は2通りあり、どちらでもよい。

### やり方A：管理者が会社アカウントを作る（おすすめ）

支払いが会社の名義で残り、担当者が変わっても引き継げる。

管理者の作業：

1. <https://platform.claude.com/> を開き、**会社のメールアドレス**でアカウントを作る
2. 左下の設定から **Billing（請求）** のページを開き、**会社のクレジットカードを登録**する
3. 同じページの **Spend limits（利用上限）** で上限額を決める（例：$10／月）。
   超えると自動で止まるので、使いすぎる心配がない
4. **Members（メンバー）** のページで、担当者のメールアドレスを招待する。
   役割は **Developer** でよい（Adminにする必要はない）

これで管理者の作業は終わり。あとは担当者が自分でキーを発行する。

### やり方B：担当者がアカウントを作る（手早い）

試すだけならこちらでもよい。管理者は会社のカードを使う許可を出すだけで、
操作は一切しない。

1. 担当者が <https://platform.claude.com/> で会社のメールアドレスでアカウントを作る
2. **Billing** で会社のクレジットカードを登録する（管理者に番号を出してもらう）
3. **Spend limits** で上限額を決める

> 注意：この場合、支払いのアカウントは担当者の名義になる。
> 本格的に使うことになったら、やり方Aに移しておくとよい。

### 担当者がやる作業（どちらのやり方でも同じ）

1. <https://platform.claude.com/settings/keys> を開く
2. **Create key** を押し、名前を付けて作る
3. `sk-ant-` で始まる文字列が**その場で1回だけ**表示される。**必ずコピーして控える**
   （閉じると二度と見られない。無くしたら作り直す）
4. アプリのフォルダの `.env` に貼り付けて、サーバーを起動し直す

> **Create key** のボタンが押せない場合は、権限が足りない。
> 管理者に Developer 以上の役割にしてもらう。

### 上限額について

- 作ったばかりの組織は、Anthropic 側でも月の上限が自動で決まっている
  （最初は低く、使っていくうちに上がる）
- それとは別に、**自分で上限額を決められる**（Billing → Spend limits）。
  超えるとAPIが止まるだけで、請求が膨らむことはない
- 最初は **$10（約1,500円）／月** くらいに絞っておけば、まず事故は起きない

## 聞かれそうなこと

| 質問 | 答え |
|---|---|
| 月いくら？ | 使った分だけ。月に数十件で数百円〜千円程度の見込み。固定費なし |
| 使いすぎが怖い | 管理画面で上限額を設定できる（Billing → Spend limits）。超えるとAPIが止まるだけで、請求は上限で止まる |
| 情報は外に出ないか | 読み取らせるのは現地メモの写真だけ。顧客名簿や図面一式を送るわけではない |
| 無くても困らないか | 手書きメモの読み取りだけが使えなくなる。ほかの機能は全部使える |
| 解約は？ | いつでも止められる。使わなければ請求も発生しない |

## 補足（社内向けの事実）

- 実際の単価はまだ実測していない。見込み額は入力と出力の分量からの概算
- アプリは解析1件ごとに実際の使用量と概算額をログに出すので、
  数件試せば実単価が分かる。高ければより安いモデルに変えられる
- キーはサーバーの `.env` に置く。利用者の端末やブラウザには配らない
- 管理画面は `platform.claude.com`（旧 `console.anthropic.com`）。
  画面の文言は変わることがあるので、見つからなければ「Billing」「API keys」で探す
