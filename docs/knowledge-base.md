# 単線結線図 記号ナレッジベース

実際の単線結線図の「上流（引込側）から下流」に向かって、現場で使われる図記号・
バリエーション・付随する入力項目を蓄積していくワーキングドキュメント。
AI解析（手書き→自動配置）の判断材料、および記号ライブラリ設計の元データとして使用する。
**今後も追記されていく前提のドキュメント。**

## 表記ルール

- 名称はすべてアルファベット略称に統一する。**「SOG」という表記は使わない。**
- 受電設備がむき出しの形態は**「オープンフレーム式」**に統一する（「開放型」等は使わない）。
- 分界点の文言は `docs/spec.md` の「図面に印字する分界点の文言（確定）」に従う。

---

## 系統構成（上流→下流）

### 1. 引込元

- パターンA：電柱（電力会社所有）
- パターンB：キャビネット（地上設置の金属製ボックス。電力会社との連携点になる場合あり）

### 2. 引込線・引込点

引込点を示す図記号が入る。

### 3. 責任分界点（引込点の直下、ほぼ同位置）

財産分界点／保安上の責任分界点／引込点の計3点が同一地点の場合、現場では「3点一致」と呼ぶ。

#### 3-1. 責任分界点パターン（作図ルール）

**パターンA：3点一致（全体の約99%）**

- 引込点・財産分界点・保安上の責任分界点が同一地点。
- 作図ルール：引込点の図記号とPAS（PASがある場合）の間に横線を引き、その横線に
  **「財産・責任分界点」**と記載する。
- PASが存在しない場合、3点一致ではない（パターンB）可能性が高い。

**パターンB：3点不一致（全体の約1%）**

- 引込点と財産分界点は同一だが、保安上の責任分界点はさらに下流（別の位置）にある。
- 現場ごとに位置が変わるため、その都度メモ書きで指示する。
- 保安上の責任分界点は、LBSまたはVCBの図記号上にあるケースが約99%
  （＝このパターンBのうち99%はLBS/VCBのどちらか。それ以外は例外として無視してよい）。
- 作図ルール：引込点と同一地点に**「財産分界点」**、該当するLBSまたはVCBの図記号の中央に
  横線を引き、その横線に**「責任分界点」**と記載する。

**AIへの確認フロー**：手書きスケッチから3点一致かどうか判別できない場合、作図前の質問として
「3点一致ですか？（はい/いいえ）」をユーザーに確認する。

### 4. 引込元〜責任分界点の間の機器

- 電柱パターン：電力会社のAS（エアースイッチ）が入る場合がある
- キャビネットパターン（2パターン）：
  - パターンA：モールドディスコン
  - パターンB：三極連動ティー型シェルター

### 5. 責任分界点の次：PAS（区分開閉器／高圧気中開閉器）

- 設置の有無：二択（あり/なし）
- PASは電柱上に設置するものであるため、図面上は「お客様電柱」として描かれる場合もある

#### 5-1. PASのバリエーション（制御装置の種類）

- 制御装置なし
- GR方式（無方向性）：ZCT（零相変流器）が入る
- DGR方式（方向性）：ZCT に加えて ZPD が入る（DGRはGRの上位互換）

#### 5-2. PASの付加機器バリエーション（制御装置の有無と独立して組み合わせ）

- VT内蔵の有無 / LA内蔵の有無
- 組み合わせ：なし / VTのみ / LAのみ / VT+LA両方

#### 5-3. PASの定格（入力項目）

- 定格電圧：6600V（旧）/ 7200V（新、よほど古くない限りこちら）
- 定格電流：100A / 200A / 300A / 400A

### 6. VCT（電力会社の計器用変成器）

- PASの直下（電柱上）にあるパターン：全体の約70%
- 電柱上になく、キュービクルまたは電気室内に収められるパターン：全体の約30%

#### 6-1. PAS〜VCT間の追加パターン（保留）

- PAS内にLAが入っていない場合、PASの直下にVCTがあるケースで、PASとVCTの間にLAが入る
  パターンがある。
- さらに、そのLAの上部にPC（カットアウトスイッチ）が入るパターンもある。
- ※この判断は基本的に図面を見れば分かるため、現時点では認識としてキープ（質問リスト化は保留）。

### 7. 引込ケーブル（電柱〜最初の受電設備入口間）

絶縁被覆されたケーブルで接続する。シールドを持つが、図面には記載不要。

#### 7-1. 付設方法（略称で表記）

- 埋設（地中）→ 表記「**埋ケ**」
- 架空（ワイヤーで引っ張る／建物内配管を通す等）→ 表記「**架ケ**」

#### 7-2. 構造・種類

CV または CVT のいずれか（全体の約99.9%がこの2択）。

#### 7-3. ケーブル横に記載する定格（3項目）

1. 定格電圧：99.99%が6600V
2. 断面積（mm²）：14 / 22 / 38 / 60 / 100 / 150 / 200 / 250 から選択。
   **一覧にない値の手入力も可**（現場の例外に対応するため）
3. ケーブル長さ：現場ごとに異なるため都度入力。不明な場合は「- m」と記載する

### 8. 電気設備（受電設備）の入口・基本構成

#### 8-1. 受電設備エリア数のパターン

- 全体の約99%は受電設備が1箇所のみ。
- 2箇所以上ある場合、以下の2パターン（図面から読み取る）。
  1. 最初の電柱から2箇所以上に分岐しているパターン
  2. 1箇所目の受電設備から送り出されて分岐しているパターン
- 運用ルール：画像から「1箇所のみ」と明確に判別できる場合は質問不要。判別できない場合のみ
  「電気設備は何箇所に分かれていますか？」を質問する。

#### 8-2. 主遮断装置の形式（最重要分岐。以降の構成すべてに影響）

- **PFS形（PF・S形）**：主遮断装置がLBS
- **CB形**：主遮断装置がVCB

判定基準（設備容量＝高圧変圧器の合計容量）：

| 設備容量 | 形式 |
|---|---|
| 300kVA以下 | PFS形（LBS）を採用可能 |
| 301kVA以上 | CB形（VCB）を採用しなければならない |

**例外パターン（3択目）**：高圧マンションで、かつ受電設備を電柱上（2本以上の電柱に構成）に
まとめているケース。屋外には主遮断装置を設置できないため、主遮断装置なし。世の中的には稀だが、
自社では約30件の実績があり無視できないパターンとして扱う。

### 9. 受電設備の基本構成（PFS形・CB形）

#### 9-1. 受電点（引込点）の図面上の扱い

電気設備の引込点は高圧ケーブルの反対側の端末にあたる。図面上はまず「高圧ケーブルの端末」が該当する。

#### 9-2. PFS形の基本構成

1. 高圧ケーブル端末
2. LBS
3. LBSから分岐し、単相変圧器・三相変圧器へ（1台ずつが最も一般的）

バリエーション：変圧器の手前にPCやLBSがもう一つ追加でつくパターンもある（図面から判断）。

#### 9-3. CB形の基本構成

1. 高圧ケーブル端末
2. DS（断路器、ディスコン）
3. DSの次にVT（**並列接続**。直列ではない）
4. DSの次に**直列接続**されるのがVCB（主遮断装置）
5. VCBのすぐ下にCT（計器用変流器）
6. CTの次にOCR（過電流継電器）
7. ここから先はPFS形と同様、変圧器へ分岐

バリエーション：変圧器の手前にLBSやPCが追加でつくパターンもある（図面から判断）。

#### 9-4. VCTの挿入位置（電気室内にある場合）

- PFS形：ケーブルとLBSの間
- CB形：ケーブルとDSの間

#### 9-5. 変圧器のバリエーション（概要）

- 単相変圧器・三相変圧器はそれぞれ複数台になる場合がある（1台ずつが最も一般的）
- 受電設備エリアが2箇所以上ある場合、さらに分岐が発生しうる

#### 9-6. コンデンサ設備（進相設備）

- 変圧器と並列に入るパターンがある（あり/なし）
- 「あり」の場合、さらにリアクトルが直列接続されるパターンとされないパターンがある
- コンデンサの台数も1台〜複数台

### 10. 特殊設備（発電機・太陽光発電所・系統用蓄電所）

#### 10-1. 発電機

- 高圧発電機 / 低圧発電機の区分
- 常用型（常に稼働）/ 非常用型（非常時のみ稼働）の区分
- 非常用発電機の場合、設置場所も図面に明記する
- 上記の区分・設置場所は図面から汲み取って作図する

#### 10-2. 太陽光発電所

場所によって構成は様々だが、ある程度パターン化されている。設備規模（大きさ）を
単線結線図に情報として載せる。

#### 10-3. 系統用蓄電所

現状、特定の施工業者が作った1パターンのみを自社で契約・使用している。変更点は基本的に
連携する電柱番号や需要場所名程度で、構成自体はほぼ固定。蓄電ユニットの規模（大きさ）を
単線結線図に情報として載せる。作成難易度は比較的低い想定。

#### 10-4. 運用方針

基本的な受電設備構成（8・9章）を土台に、設備規模が大きくなる／台数が増える形で応用されていく。
特殊設備は事前にパターンを本ナレッジベースにインプットしておき、そこから適切な図面を生成する方針。

### 11. 変圧器のバリエーション（詳細）

#### 11-1. 単相用変圧器

基本的に1種類のみ（バリエーションなし）。

#### 11-2. 三相用変圧器（基本の結線方式）

- Y-Y結線（スター・スター結線）
- Δ-Δ結線（デルタ・デルタ結線）
- Y-Δ結線（スター・デルタ結線）
- Δ-Y結線（デルタ・スター結線）

#### 11-3. スコット結線（スコット変圧器）

三相交流から2種類の単相三線式を取り出す結線方式。発電機の三相回路のアンバランスを防ぎつつ、
単相電源を取得する用途で使用される。

#### 11-4. 単相変圧器を組み合わせて構成するパターン

- V-V結線：単相変圧器を2台接続して構成
- Δ-Δ結線（単相変圧器3台版）：11-2の三相変圧器単体によるΔ-Δ結線とは別のパターン
- 並行運転による倍容量化：単相変圧器2台を並行運転させ、倍の容量の単相変圧器として使用する

## 受電設備形態（設置場所）の表記ルール（共通ルール・エリア単位）

VCT以降の受電設備（キュービクル等）は、建物内の「どこにあるか」を図面上で明確にし、
図面を見た人がその場所に迷わずたどり着けることを目標に表記する。

### 形態の分類

- **キュービクル式**：金属製の箱に収められた形態
- **電気室**：部屋の中に設備がある形態。さらに以下に分岐
  - 電気室内にキュービクルがあるパターン
  - 電気室内に設備がむき出しで設置されているパターン → **「オープンフレーム式」**に統一

### 設置場所の付記

屋内／屋上／屋外（地上）等の設置階層・場所も併記する。オープンフレーム式は99%が建物内（屋内）。
ただし例外として屋上・中2階・半屋外等のケースもある。

### 表記例

- 「電気室（1階、屋内）」
- 「地上キュービクル（駐車場横）」
- 「屋上キュービクル」
- 「オープンフレーム式（2階）」

### 重要な設計要件：1プロジェクト内に複数の受電設備エリアが存在しうる

- 1つの建物・現場であっても、受電設備が複数箇所（例：3〜4箇所）に分かれて設置されることがある。
- 各エリアごとに形態と設置場所が異なる場合がある。
- → データ構造上、`Project.substationAreas[]` として複数登録できるようにし、
  エリアごとに形態・設置場所のラベルを持たせている（`packages/core/src/index.ts`）。

## 作図ルール（記号レビューで確定したもの）

### 受電設備エリアの外枠

- 受電設備が**2箇所以上ある場合のみ**、各エリアを**一点鎖線の四角**で囲う。
- **1箇所しかない場合は全体を囲わない。** かえって分かりにくくなるため。
- 枠の具体的な形は代表図面を参照する（図面到着待ち）。
- 実装：`shouldDrawAreaFrames()`（`packages/core`）／`substation-area`（`packages/symbols`）

### 接続点・分岐点

- **線と線の交点に点（黒丸）は置かない。** 接続点マークの図記号は廃止した。

### 母線

- 現在の図記号のままでよい。

### 保護継電器

- **丸ではなく長方形で囲い、長方形の中に継電器の種類を記載する。**
- 手書き図面に書かれている記号を**そのまま**載せる。
- 一覧にない記号が出てきた場合、AI解析は自動で判断せず、ユーザーに次の2点を確認する。
  1. 誤字ではないか
  2. 新しい継電器であれば、一覧に追加してよいか
- 種類の一覧は `RELAY_TYPES`（`packages/symbols/src/defs/protection.ts`）にデータとして持つ。
  新しい継電器はここに1行追加するだけで、パレット・AI解析・入力欄に反映される。

| 略称 | 名称 |
|---|---|
| OCR | 過電流継電器 |
| GR | 地絡継電器（無方向性） |
| DGR | 地絡方向継電器（方向性） |
| OCGR | 地絡過電流継電器 |
| OVGR | 地絡過電圧継電器 |
| UVR | 不足電圧継電器 |
| OVR | 過電圧継電器 |
| UFR | 不足周波数継電器 |
| OFR | 過周波数継電器 |
| RPR | 逆電力継電器 |
| UPR | 不足電力継電器 |
| DSR | 方向短絡継電器（正式名称は要確認） |
| 2E | 電動機保護継電器（過負荷・欠相） |
| 3E | 電動機保護継電器（過負荷・欠相・反相） |

### 変圧器

- **三相変圧器の図記号は確定。** 単相変圧器の図記号は見本待ち。
- **単相変圧器3台のΔ-Δ結線**：専用の図記号は作らない。通常の三相Δ-Δ結線の図記号を使い、
  定格の入力欄に「単相変圧器×3」と記載するだけでよい。図記号を変えるとかえって分かりにくくなる。
- **V結線**：丸を縦に2つ並べ、**それぞれの丸の中に「V」を記載**する。構成欄に「単相変圧器×2」と記載。
  2台の定格容量が異なる場合があるため、**容量は2台分を別々に記載する**（例: 50kVA、30kVA）。
- **単相変圧器の並行運転**：現在の構成でよい。
- **スコット変圧器**：ほとんどが低圧から低圧への変換のため、**通常は単線結線図に記載しない。**
  「低圧スコット変圧器」などと指示されたときだけ配置できるようにしておく。図記号は見本待ち。

### 計器

- 電圧計・電流計・電力量計は**低圧設備**であり、図面に記載することはほぼない。
  ただしデータとしては保持する。
- **位相計**（力率計）を追加。丸の中に `cosθ` と表記する（表記は要確認）。

### 見本図面から確定した描き方（2回目のレビュー）

| 記号 | 描き方 |
|---|---|
| 電柱 | 円の**左半分を縦線でハッチング**し、下に引下線。名称は「中電柱：猪子山（分）81」の形式 |
| 高圧ケーブル端末 | **三角形**。頂点が常にケーブル側を向く（受電側の端末は180°回転） |
| 分界点 | 横線を主回路から**左へ長く伸ばし**、その左上に文言を**太字**で記載 |
| LBS（PF付） | 上部に**横バー＋丸**（固定接点）、**斜めの可動刃**、可動刃の上に**紡錘形のヒューズ**。記載例「LBS 7200V 200A PF×3 7200V G50A T40A」 |
| PF（単体） | 導体方向に細長い長方形。横向きの分岐に付く場合は90°回転 |
| PAS | **実線の四角**。内蔵機器（ZCT/VT/LA）は枠内に配置し、GR/DGRは枠の外に描いて制御線を引く。記載例「PAS 7200V300A VT,LA内蔵型」 |
| ZCT | 円の中に**斜線** |
| VT | **横向きに並べた二重丸**（接地なし）。手前にPFが入る。記載例「VT＋PF 6600/110V」 |
| VCT | 実線の四角の中に、上段：VT（二重丸・横向き）、下段：CT（単円）。それぞれ二次側を右へ引き出す |
| SR | 四角の中にコイル。記載例「SR 3φ6.38kvar 243V」 |
| SC | 四角の中にコンデンサ（2枚の板）。記載例「SC 3φ106kvar 7020V」 |
| ZPD | 四角の中にコンデンサ（2枚の板）と変圧器（二重丸）、下に接地。出力はOVGRへ |
| 保護継電器 | 長方形の中に種類を**字間を空けて**記載（例「O V G R」） |

### ケーブルの注記（3行で書く）

```
埋ケ
CVT
6600V 100mm2 20m
```

1行目：付設方法（埋ケ／架ケ）、2行目：構造（CV／CVT）、3行目：定格電圧・断面積・長さ。
長さ不明のときは「- m」。埋設ケーブルが地表面を横切る箇所には**太い横線**（地表面）を引く。

### 外枠の使い分け

- **機器の外箱**（キュービクル・電気室）＝**実線の四角**。ラベルは枠の**左上・外側**に記載する（例「キュービクル式（2階屋外）」）。受電設備が1箇所ならこれだけを描く。
- **受電設備エリアの区分枠**＝受電設備が**2箇所以上のときだけ**描く。線種は確認中。


### 見本図面から確定した描き方（3回目のレビュー）

| 記号 | 描き方 |
|---|---|
| DS | 上に**横バー（固定接点）**、下に**丸（可動接点）**、可動刃は**右上がり**。記載例「DS 7200V 400A」 |
| 単相変圧器 | 二重丸。**上の円に横線1本、下の円に横線3本**（二次側が単相三線式）。記載例「電灯 / Tr / 1φ200kVA / 6600V/210-105V」 |
| V結線 | 二重丸のそれぞれに**V**。容量は2台分を別行で記載。記載例「V結線 / Tr / 1φ50kVA / 1φ75kVA / 6600V/210-105V」 |
| 変圧器の円の大きさ | すべての変圧器記号で見本図面（電灯Tr）の比率に統一 |
