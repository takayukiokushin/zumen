## 3. 途中で出た失敗と、その原因（すべて、検査の側）

### 3-1. 5段目（1回目）：位置が失われた 1件（種3592）
- 電柱の VCT（線の上に乗せる記号）を、横にだけ動かしたものが、作り直しで、線の真上に戻り、動かした記録ごと無くなる。これは、もとからの決まり（線の上の記号は、横の動きを数えない）どおり。検査が、「記録が無くなった」場合を、数え漏らしていた。
- 検査の判定を直しました（図面の作りは、変えていません）。

### 3-2. 6段目（1回目）：位置が失われた 9件（5つの図面）
- どれも、「出口のつなぎ口のない記号（変圧器・開閉器など）を、線の上に乗せる記号（CT・ZCT）に、手で差し替える」操作のあと。
- **画面は、この差し替えを断ります**（形のつなぎ方が違うため）。検査が、画面が断る操作まで、でたらめに試していた。
- 検査を、画面と同じ決まりにそろえました（画面が断る操作は、試さない）。同じ種類の問題が、5段目にもあるので、5段目もそろえました。
- 図面の作りは、変えていません。種4126だけは、前回の直しのあとに出るようになりましたが、同じ操作（画面が断る差し替え）でした。
- 4つの図面は、前回の直しより前のコードでも、同じ結果でした（もとからのもの）。

## 4. うまくいったこと／うまくいかなかったこと

**うまくいったこと**

- 環境が、途中で止まることは、ありませんでした（見張りが、効いています）。

**うまくいかなかったこと**
- 検査の側の問題が2つありました（上の3-1・3-2）。検査を直して、回し直しました。

**そのままのもの**

- 作り直しの、エリア2〜3か所での崩れ（全体の0.1〜0.4%）。もとからあるもので、決めた範囲内です。
