# 設置の日のメモ（利用者の ID と権限）

会社のMacをサーバーにする日に、`docs/server-setup.md` の 2-7「利用者を登録する」で使うメモ。
**パスワードはここに書かない**（決めた人が、自分のメモに控える）。

アカウントは、サーバーの `data/zumen.db` に入る。GitHub には上がらないので、
**ここ（開発用の環境）で作っても会社のサーバーには引き継がれない。設置の日に、あらためて登録する。**

## 決めた ID

| ID | 役割 | 種類（書き方） | できること |
|---|---|---|---|
| `zumen_kanri` | 管理者（hoan・jimu の上位） | `admin` | すべての案件＋画面から利用者の管理 |
| `zumen_hoan` | 保安 | `member` | 案件をみんなで共有する |
| `zumen_jimu` | 事務 | `member` | 案件をみんなで共有する（hoan と同じ権限） |
| `zumen_rensyu` | 練習環境 | `sandbox` | 自分が作ったものだけ。他の3つとはデータを共有しない |

- `zumen_hoan` と `zumen_jimu` は横並び（同じ権限）。その上に `zumen_kanri` が来る。
- 練習環境は、他の3つとは別のアカウント。**練習環境で作った案件は、練習環境の中でしか見えない**
  （kanri にも見えない）。練習環境で編集した内容は、練習環境にだけ反映される。

## 登録するときのコマンド（設置の日）

パスワードは、決めたものを入れる（ここには書かない）。

```sh
pnpm --filter @zumen/server user:add zumen_kanri 管理者 ここにパスワード admin
pnpm --filter @zumen/server user:add zumen_hoan 保安 ここにパスワード member
pnpm --filter @zumen/server user:add zumen_jimu 事務 ここにパスワード member
pnpm --filter @zumen/server user:add zumen_rensyu 練習用 ここにパスワード sandbox
```

- 名前（「管理者」「保安」「事務」など）は画面に出る表示名。変えたければ、設置の日に決める。
- 登録したら `pnpm --filter @zumen/server user:list` で4つ並んでいるか確かめる。

## 練習環境は、設置の日に作る（いまは作らない）

開発用の環境（Claude Code を動かしている場所）では、練習用のアカウントは作らない。
会社のサーバーを動かす日に、上のコマンドで `zumen_rensyu` を登録する。

## 練習環境で本番の案件を使いたいとき

`zumen_rensyu` でログインして「図面一覧」を開くと、**「本番の案件をコピーして練習する」**の欄がある。

- 欄を開き、案件の横の「コピーして練習する」を押すと、**コピー**が作られてそのまま開く（名前に「（練習）」が付く）。
- もとの本番の案件（回答・図面・写真）は、**何も変わらない**。コピーの編集は、コピーにだけ反映される。
- コピーした案件は、`zumen_rensyu` にしか見えない（kanri・hoan・jimu には見えない）。
- コピーした時点の内容なので、あとで本番の案件が更新されても、コピーには反映されない。もう一度コピーする。

## 設置の日に気をつけること（チャットにしか残っていなかったこと）

- **ZIP のダウンロード元：** GitHub には、いま `claude/single-line-diagram-app-h1mp73` という名前のブランチしかない。
  手順書 2-2 の「Code → Download ZIP」は、通常、標準のブランチ（main など）を落とす。
  設置の日は、ZIP を落とす前に、**このブランチの内容を標準のブランチにも反映する**か、
  **ブランチをこの名前に切り替えてから ZIP を落とす**かを決める。
- **引き継がれないもの：** API キー（`.env`）と案件・アカウント（`data/`）は GitHub に入らない。
  API キーは設置のときに本人が貼り付ける。アカウントは上の表のとおり、設置の日に登録する。
- **順番：** サーバーの設置 → アカウントの登録 → 最後にリポジトリの非公開化（先に非公開にすると、ダウンロードが通らなくなる）。

## いまは保留にしていること（必要になったら声をかける）

- 会社の外から使うための設定（Cloudflare のトンネルとアクセス制限）。最初から教え直す約束
- 保存の前にログインが切れたとき、入力を残したまま入り直せる画面
- 「利用者の管理」の画面を Esc キーで閉じる
- 主遮断装置の形式が未回答のときに VCB を選んだら、CB形の形式を自動で入れるかどうか
- 主遮断装置の形式と、高圧マンション（電柱上構成）を結びつける案
- PAS・PGS・UGS の内蔵 VT・LA の質問の揃え方
- 表題欄を2行にしたときの枠の高さ（実際に試してから決める）
- 定格電圧の選択式を、LBS など他の場所にも広げるか、変わった電圧の手入力を許すか
