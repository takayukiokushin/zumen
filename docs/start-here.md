# 会社のMacのClaude Codeに、最初に貼るテキスト

下の枠の中を**まるごとコピーして、会社の Mac mini の Claude Code に貼り付ける**。
これ1つで、設置から利用者の登録、リポジトリの非公開化まで最後まで進む。

> このテキストは**単体で成り立つ**ように書いてある。
> 手元に何のメモが残っていなくても、これさえ貼れば進められる。

```
あなたには、会社の Mac mini を「単線結線図作成アプリ」のサーバーにする作業を
手伝ってもらいます。私はプログラマーではありません。専門用語を使わず、
1つずつ区切って、私が「次」と言ってから進めてください。

────────────────────────────────────────
■ このアプリについて
────────────────────────────────────────
高圧受電設備の単線結線図を作る社内アプリです。
Mac mini 1台を「サーバー役」にして、社内の他のパソコンやiPadからは
ブラウザで住所を開くだけで使えるようにします。
アプリを入れるのはこの1台だけです。

置き場所: https://github.com/takayukiokushin/zumen
（ブランチは claude/single-line-diagram-app-h1mp73。これが既定です）

────────────────────────────────────────
■ まずやってほしいこと
────────────────────────────────────────
1. ~/Desktop/zumen があるか確認してください。
   ・あれば、その中の CLAUDE.md と docs/server-setup.md を読んでください。
     そちらが正式な手順書です。以降は下の要約より、そちらを優先してください。
   ・なければ、下の【手順】の 1 から始めてください。

2. 読み終えたら、私に「どこまで終わっていますか」と聞いてください。
   終わっている部分は飛ばして構いません。

3. 作業は次の順番で進めます。順番を入れ替えないでください。
     (1) サーバーの設置        … 下の【手順】1〜11
     (2) 利用者（アカウント）の登録 … 下の【手順】7
     (3) リポジトリの非公開化    … 下の【手順】12  ← 必ず最後

────────────────────────────────────────
■ あなたが代わりにやってよいこと
────────────────────────────────────────
ターミナルの操作（ダウンロード、展開、コマンドの実行、ログの確認）は、
いちいち私に打たせず、あなたが実行してください。
ただし次の4つは私がやります。あなたは「やってください」と言って待ってください。
  ・Node.js のインストール（画面をポチポチする作業）
  ・APIキーの貼り付け（秘密の文字列なので私が入れます）
  ・パスワードを決めること
  ・Macのシステム設定と、GitHubの画面での操作

破壊的な操作（ファイルを消す、フォルダを入れ替える）の前には、必ず私に確認してください。

────────────────────────────────────────
■ 手順（docs/server-setup.md が読めない場合は、これだけで進めてください）
────────────────────────────────────────
1. Node.js があるか確認: `node -v`
   v22 以上でなければ、私に https://nodejs.org/ja の LTS版 を入れるよう頼む。
   入れ終わったらターミナルを開き直す必要があります。

2. アプリを取ってくる。公開中なら、あなたがこれを実行してよい:
     cd ~/Desktop
     curl -fL -o zumen.zip https://github.com/takayukiokushin/zumen/archive/refs/heads/claude/single-line-diagram-app-h1mp73.zip
     unzip -q zumen.zip && rm zumen.zip
     mv zumen-claude-single-line-diagram-app-h1mp73 zumen
   取れない（非公開にしてある）場合は、私に
   「GitHubにログインして Code → Download ZIP で落としてください」と頼み、
   ダウンロードフォルダの zumen-*.zip を使ってください。

3. ダウンロードの警告を外す:
     cd ~/Desktop/zumen && xattr -dr com.apple.quarantine .

4. 動作確認: `./test-mac.command`
   初回は5〜10分かかります。「すべて正常」と出れば成功。
   「問題が見つかりました」なら test-result.txt の中身を見てください。

5. APIキーを置く:
     cp .env.example .env && open -e .env
   テキストエディットが開くので、ANTHROPIC_API_KEY= の右側を
   私がAPIキーに書き換えて保存します。= の前後に空白を入れない、引用符も不要。
   確認: `pnpm --filter @zumen/server apikey`
   「✓ 利用券は使えます。」で成功（かかる金額は1円未満）。
   「残高がありません」と出たら、クレジットの購入が必要です。私に伝えてください。

6. 控え（バックアップ）の場所を決める:
   同じ .env の一番下 BACKUP_DIR= に、Dropboxなど同期フォルダのパスを書く。
   行頭の # を消すこと。例:
     BACKUP_DIR=/Users/ユーザー名/Dropbox/単線結線図_控え

7. 利用者を登録する。アカウントは3種類あります。
     admin   … 管理用。すべての案件＋画面から利用者の管理ができる
     member  … 標準。案件をみんなで共有する。ふだん使うのはこれ
     sandbox … 練習用。自分が作ったものだけ。他の人には見えない
   最初はこの3つを作ります。パスワードは8文字以上で、私が決めます:
     pnpm --filter @zumen/server user:add kanri 管理者 <パスワード> admin
     pnpm --filter @zumen/server user:add fujielex 株式会社フジエレックス <パスワード> member
     pnpm --filter @zumen/server user:add renshu 練習用 <パスワード> sandbox
   一覧:         pnpm --filter @zumen/server user:list
   消す:         pnpm --filter @zumen/server user:remove <ID>
   パスワード変更: pnpm --filter @zumen/server user:passwd <ID> <新しいパスワード>
   user:list に test というIDが残っていたら必ず消してください（パスワードが公開情報のため）。
   ※ これ以降、利用者の追加・削除・パスワード再設定・ログインの解除は、
     管理用アカウントでログインして画面右上の「利用者の管理」から行えます。
     ターミナルが要るのは、一番最初の管理用アカウントを作るときだけです。

8. 自動で立ち上がるようにする: `./install-autostart.command`

9. 住所を控える: `pnpm start` の2行目に出る
     社内の他のパソコンからは: http://192.168.x.x:8787
   これを私に見せてください。控えます。確認できたら control + C で止めて構いません。

10. Macの設定を2つ変えるよう私に頼んでください。
    ・システム設定 → ロック画面 → ディスプレイがオフのときに自動でスリープさせない をオン
    ・システム設定 → ユーザとグループ → 自動ログイン をオン
    （スリープやログイン画面で止まると、サーバーも止まります）

11. 別のパソコンのブラウザで 9 の住所を開き、ログインできれば完成。
    つながらないときは、システム設定 → ネットワーク → ファイアウォール → オプション で
    Node の通信を許可するよう私に頼んでください。

12. 【いちばん最後】リポジトリを非公開にする。
    1〜11 が終わって、他のパソコンから使えることを確かめてから行います。
    順番を守ってください。先に非公開にすると 2 のダウンロードが通らなくなります。
    私に次の操作を頼んでください:
      1. GitHubにログインした状態で
         https://github.com/takayukiokushin/zumen を開く
      2. 上の「Settings」を押す
      3. 一番下までスクロールし、赤い枠「Danger Zone」の中の
         「Change repository visibility」→「Change visibility」
      4. 「Make private」を選ぶ
      5. 確認のため takayukiokushin/zumen と入力
      6. 「I understand, change repository visibility」を押す
    終わったら、リポジトリ名の横が Private になっていることを一緒に確認してください。

    非公開にしたあと、アプリを新しくする方法が変わることも教えてください:
      ・古い zumen-*.zip がダウンロードフォルダにあれば捨てる
      ・GitHubにログインした状態で Code → Download ZIP
      ・~/Desktop/zumen/update-mac.command をダブルクリック
      ・ブラウザで command + shift + R で読み込み直す

────────────────────────────────────────
■ 守ってほしいこと
────────────────────────────────────────
・.env（APIキー）と data/（案件のデータ）は、何があっても消さない・引き継ぐ。
  この2つさえ無事なら、他は何度でも入れ直せます。
・APIキーはこの Mac mini 1台だけに置く。他のパソコンやチャットに貼らない。
・リポジトリの非公開化は必ず最後。
・困ったら ~/Desktop/zumen/docs/first-aid.md（困ったとき用の1枚）を見てください。

────────────────────────────────────────
■ 全部終わったら
────────────────────────────────────────
次の5つを、私がメモできる形でまとめて出してください。
  1. 社内の他のパソコンから開く住所（http://192.168.x.x:8787）
  2. 作ったアカウントのID3つ（パスワードは書かないでください）
  3. 控え（バックアップ）の保存先
  4. アプリのフォルダの場所
  5. 次にアプリを新しくするときの手順（3行で）

それでは、まず ~/Desktop/zumen があるか確認するところから始めてください。
```

## このテキストをどこに置いておくか

- **印刷して、Mac mini のそばに置く**（いちばん確実）
- Macの「メモ」アプリに貼っておく
- このファイル自体は `docs/start-here.md`（GitHubからも読める）

> アプリのフォルダの中にもあるが、フォルダが無い状態では読めない。
> **フォルダの外にも1部残しておくこと。**
